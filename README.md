## 我的 AI 协作工作流怎么搭

**需求与验收标准 → 工作包与素材 → AI 辅助实现 → 预览和验证 → 发布、备份与交接**

这套流程在平台多次更新中逐步形成。我先定目标、边界和验收标准，把素材、实现和验证资料按职责组织；重复检查交给脚本，重要取舍保留具体预览。每次交付记录版本、验证结果和下一步，让项目换一次对话仍能继续推进。
